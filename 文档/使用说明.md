# 射箭训练助手 — 使用说明

一款 **Windows 桌面程序**（不是网页），用于记录射箭训练成绩、查看统计、生成成绩海报。数据保存在本机，无需联网即可使用核心功能。

---

## 一、运行环境

| 项目 | 要求 |
|------|------|
| 系统 | Windows 10 / 11 |
| Java | **exe 版**：无需安装；**zip 版**：需 Java 17+ |
| 磁盘 | 约 200～400 MB（含识别模型与依赖） |
| 网络 | 发行 zip **解压后离线可用**；开发源码包首次编译需联网 |

---

## 二、如何打开程序

### 方式 A：exe 版（零配置，推荐）

作者运行 **`build-exe.bat`** 生成 `release/ArcheryAssistant/` 后打成 zip 分发。

用户步骤：

1. **解压**整个 **`ArcheryAssistant`** 文件夹（不要只复制 exe）。
2. **双击 `ArcheryAssistant.exe`**。
3. **无需**安装 Java、**无需**编译、**无需**训练模型。

文件夹内已内置 Java 运行环境（`runtime/`）、程序（`app/`）、识别模型（`models/`，若有）。

### 方式 B：发行 zip（需 Java 17）

见 `prepare-release.bat` 生成的文件夹，需用户电脑预装 Java 17+。

### 方式 C：开发源码包（仅开发者）

1. 解压后双击 `启动射箭助手.vbs`（会自动编译、可能联网下载依赖）。
2. 需要 JDK 17+ 与网络（首次）。

> **不要**把 `archery app-v1` 或带 `training/` 的源码文件夹直接发给用户。

## 三、首次使用

1. **登录 / 注册**  
   - 输入账号、密码（密码至少 4 位）。  
   - 账号为**本地账号**，数据只存在你的电脑上。  
   - 可勾选「记住登录状态」。

2. **设置（可选）**  
   左侧导航 → **设置**：  
   - 界面语言（中文 / English）  
   - 字体大小  
   - 射手姓名（用于成绩海报）  
   - **重新观看软件指引**（逐步弹窗教程）

3. **新手教程**  
   左侧 **新手教程** 可随时打开，共三个标签：  
   - **软件教程**：第 1～3 课（第 1 课含 7 个步骤的功能说明；第 2 课高效使用；第 3 课筹备中）  
   - **入门课程**：第 1 课基础动作（安全、站姿、握弓等 8 步）；第 2 课进阶要点；第 3 课筹备中  
   - **大神教学**：界面预览，视频功能敬请期待  

   首次登录后会自动弹出 **7 步软件指引**（可跳过）；软件教程页可点「重新播放欢迎指引」。

## 五、开始一场训练

点击 **训练** 或首页 **开始训练**，先选择录入方式。**同一场训练只能选一种方式，中途不能混用。**

### 1. 速记环数（快速）

适合：练完一组后，只记得各环打了多少支，不需要落点图。

**流程：**

1. **场次设置** — 选择本场 **赛制**（整场比赛统一，开始后不可改）：
   - 练习：每组 **12** 支箭  
   - 排位赛：每组 **6** 支箭  
   - 淘汰赛：每组 **3** 支箭  
   - 还可填：距离、弓种、磅数、箭种、场地等  

2. **速记环数** — 用 **+ / −** 录入 X、10～1、M 各环的箭支数（左右两栏，无需滚动即可填完）。  
3. 本组箭数满后，点 **「完成本组」** 进入下一组（不会自动跳组）。  
4. 左侧 **组数目录** 可点击回到任意一组修改。  
5. 保存：
   - **保存草稿** — 未完成也可退出，之后在历史记录继续  
   - **保存整场训练** — 标记为已完成  

### 2. 精确记录（落点）

适合：需要落点分布、虚拟靶图，或上传靶纸照片辅助识别。

**流程：**

1. **场次设置**（同上，赛制锁定后不可改）。  
2. **虚拟靶录入**：
   - **直接点击** 虚拟靶上的落点（推荐）；  
   - **上传照片识别 / 计分** — 本地识别并标定靶面后默认自动估分，人工校对可选；  
   - 可 **拖动** 落点修正；  
   - 落点用 **×** 表示箭头方向；**压线算高环**。  
3. 可用 **缩放** 放大靶心区域，便于精调。  
4. 完成本组、切换组数、保存草稿 / 保存整场 — 与速记环数类似。  
5. 部分界面提供 **本组分析 / 教练建议**（基于落点散布的规则提示，非医疗建议）。

## 六、历史记录与草稿

- **草稿**：标题带 `[草稿]`，点 **继续编辑** 接着记。  
- **已完成**：可 **总结** 查看逐组回顾，或 **海报** 导出图片。  
- **删除**：永久删除该场次（请谨慎）。  
- 若已保存草稿且之后没有新改动，退出时不会再反复询问是否存草稿。

## 七、成绩海报

1. 进入 **成绩海报**。  
2. 选择一场已完成的训练。  
3. 预览后 **导出 PNG**，可发朋友圈或提交作业截图。

## 八、照片识别与计分

**不配置也能完整使用**：精确记录请直接在虚拟靶上点击落点；速记环数完全不依赖识别。

1. 在精确记录页点击 **上传照片识别 / 计分**，选择照片，等待本地 NAS 返回候选。
2. 原图上可补点、拖动和排除误点。全部候选都会保留，不按每组箭数自动截断；请选择属于本组的箭。
3. 选择完整 1–10 环靶或局部 5–10 环靶（蓝色外缘）。核对自动匹配的主靶和环线，必要时进入 **调整标定** 拖动「心、右、下」控制点；勾选「已核对靶型与环线」，点击 **确认标定**。
4. 默认采用自动估分，边界点标黄提示，无需逐枝确认即可应用。人工校对可选：在表格「采用环数」改分，手工值优先；选择「自动估分」或点击「恢复自动估分」可恢复默认。估分使用中心点，不使用模型框宽作为箭径，也不依赖窗口缩放。
5. 点击 **确认并应用本组**。本组已有箭时，需确认替换；之后仍使用原有完成本组和保存场次流程。
6. 尚未确认时可 **保留校对草稿**，再在训练页 **保存草稿**。重新打开草稿后点击照片校对继续；待确认照片不进入正式成绩。
7. 场次回顾中可 **查看本组照片**。照片落点通过照片校对修改；虚拟靶直接拖点用于原有手动记录。

无候选或推理失败不会生成零分箭。仅对实际采用的有效落点估分；靶外点自动估为 M 并标黄，可按需排除邻靶候选或修改环数。首次支持正面或轻微斜拍的仿射近似标定；明显透视、弯曲靶纸或无法辨认的压线可重新拍摄或人工调整。X 使用室外训练模板，室内复合弓等规则不在当前模板内。

普通用户不需要训练模型或安装 Python。NAS 发行包内置私有推理运行时，不含训练环境。旧 ONNX 路径和手动录入继续保留；已有成绩不会因启用 NAS 被重新计算。

## 九、数据存在哪里

| 内容 | 位置 |
|------|------|
| 训练记录 | `data/archery-data.json` |
| 用户设置 | 同上（含语言、字号等） |
| 照片与校对来源 | `data/photos/`，校对元数据在主 JSON 中 |
| 上次有效数据备份 | `data/archery-data.json.bak` |
| 识别模型 | `models/*.onnx`、`models/*.tflite` |
| LLM 教练（若配置） | `config/llm.properties`（可选，一般用户可忽略） |

**备份**：复制整个 `data` 文件夹即可备份所有训练记录。  
**迁移**：在新电脑上解压程序，把旧 `data` 文件夹覆盖回去。

## 十、常见问题

**Q：exe 版双击没反应？**  
- 确认解压了 **整个** `ArcheryAssistant` 文件夹，未单独移动 exe。  
- 解压到非系统保护目录（如 `D:\射箭助手`），避免权限问题。  
- 查看同目录 `请先阅读.txt`。

**Q：zip 版（需 Java）双击没反应？**  
- 确认已安装 Java 17+（https://adoptium.net/）。  
- 开发源码包首次需联网下载 `lib/` 依赖。

**Q：上传靶纸识别？**  
- 在精确记录中上传照片，确认主靶标定后默认采用自动估分，可直接应用到当前组；边界标黄，人工校对可选。运行时不可用时仍可手动记录。

**Q：赛制选错了？**  
- 已有记分后赛制锁定；请新开一场训练。

**Q：窗口内容被挡住？**  
- 非核心区域（如最近场次）可滚轮查看；录入区会尽量保持完整可见。  
- 可在 **设置** 中调小字号。

**Q：如何卸载？**  
- 直接删除程序文件夹即可；数据在 `data/` 里，删前请先备份。
