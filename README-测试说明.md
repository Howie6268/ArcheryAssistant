# 射箭训练助手 Windows 测试包

构建：20261025-autoscore-r2；包含 NAS 入靶识别、靶面匹配、自动估分及可选人工校对。

1. 将压缩包完整解压到新的文件夹，双击 `ArcheryAssistant.exe`。Java、Python、模型与 C++ DLL 已内置，无需联网安装。
2. 本测试包使用空白 data/config。首次启动创建本地测试账号；不会携带开发机上的账号或训练历史。
3. 精确记录 → 上传照片识别/计分 → 核对主靶和靶型 → 勾选已核对 → 确认标定。随后可直接应用自动估分，黄色边界提示无需逐枝确认。
4. 按需修改“采用环数”或排除邻靶点，再应用本组，完成本组并保存场次；去历史检查总分与照片。黄色靶外点默认估为 M。
5. 验证保留照片草稿、保存草稿、关闭重启、重新打开以及人工改分/恢复自动估分。

已有数据若需迁入，先关闭软件并备份旧版整个 data 文件夹，再将副本放入新测试目录。不要覆盖原安装目录。自动计分不会在加载旧记录时重算历史分数。

如果模型加载失败，双击 `NAS运行环境检查.bat`，将 logs/nas-self-check.log 和 logs/nas-self-check.json 发回排查。检查只运行空白输入，不读取照片、训练数据或网络服务。

本包在 macOS 上编译并组装：复用已有 Windows x64 jpackage 启动程序与 Java 25 运行时，应用 jar 来自本次最新 Java 17 编译；已经完成静态 DLL/符号、归档完整性和跨平台 Java 回归检查，尚未在 Windows 实机运行。请在 Windows x64 上验收。

详细使用说明见 文档/使用说明.md。构建来源和文件摘要见 build-info.json、FILE_MANIFEST.json。
